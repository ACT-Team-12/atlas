# ATLAS for Android

The native Android app for ATLAS. It matches the iPhone app (`mobile/ios` on `feat/ios-app`) screen for screen and does the things the web app cannot:

- **Reads the paper on the phone.** "Scan my paper" opens the ML Kit Document Scanner (`play-services-mlkit-document-scanner`, runs on the phone, its models come from Google Play services). Text is read with the bundled ML Kit text recognizer (`com.google.mlkit:text-recognition`, ships inside the app, works offline). If the scanner module is not on the phone, the app asks Play services to fetch it for next time and opens the system photo picker instead. The photo never leaves the phone. The person checks and edits the recognized text, and only that text is sent.
- **Paper first, with the double-check.** After a read, the app asks the server's second check (`POST /api/meaning`, the same body the website sends) whether each explanation matches its line. Only a certified explanation leads; every other step shows "Your paper says:" with the verbatim quote first and the explanation underneath, marked as not double-checked. Read aloud, Send to family and reminders carry an explanation only when it is certified, otherwise the quote alone (a port of `web/src/lib/paperFirst.ts`). Plan steps are labelled as suggestions and carry the paper's words for the steps they come from. Lab rows lead with the report's own line.
- **Helper links.** A link made on the website's `/helper` page (`https://atlas-team12.vercel.app/#try&via=helper&lang=es&level=simple&zip=30310`) opens the app with that language, reading level and ZIP picked and the same banner, checked against the same allow-lists (`data/HelperLink.kt`, a port of `web/src/lib/helperLink.ts`). The link is an Android App Link for the site's root page, verified by `web/public/.well-known/assetlinks.json` (the release key's SHA-256). The first plan built after opening a link is counted once as a helper-link plan; the link itself is never sent.
- **Outdated plan.** If the text, language or reading level changes after a read, or the steps, barriers, note or place change after a plan, the screen says so and turns off read aloud, sharing and reminders on the plan until it is updated (`web/src/lib/staleGuard.ts`). A plan saved by the 1.0 app, which kept no fingerprints, gets them rebuilt from what it saved, so it can show the note too.
- **Lines on your paper we didn't turn into steps.** Under the steps, the instruction-like lines no kept step quotes, collapsed behind one heading, with a polite screen-reader announcement. The server sends `missed_lines` with the read (`MissedLinesPayload` in `web/src/lib/missedLines.ts`); the phone only compares numbers, so it updates on every Remove and Undo. Hidden when the server could not check the paper's language or sent no check. `mobile/shared/missed-lines-vectors.json` holds the website's answers and `MissedLinesTest` replays them.
- **Reminders.** "Remind me" on any care step or plan step schedules a local notification with the step's kind (never the AI's title unless certified) and the line quoted from the paper. It uses an exact alarm when Android allows it, otherwise an alarm that goes off within 10 minutes of the chosen time. Reminders are re-armed after a phone restart or an app update, and each time the app opens (Android drops an app's alarms when it is force-stopped). All reminders are listed with delete.
- **Read aloud** with the phone's text-to-speech voices in the language the steps were written in (so outdated steps keep their own voice), one line at a time, with a Stop button. If the phone has no voice for that language, the screen says so.
- **Saved on this phone.** The last care steps and plan are kept as JSON in the app's private files, with the time they last changed (changing the language, level, ZIP or note, or opening a helper link, keeps that time). Backup and device transfer are turned off for app files. "Clear from this phone" removes them and every ATLAS reminder.
- **Call, directions, links.** Call opens the dialer (nothing is dialed for you), Transit directions opens Google Maps in transit mode, program pages open in an in-app browser tab. Call and Open are hidden when the server sends an empty phone or link.
- **Location** (optional, approximate, one time) for nearest clinics. Locations outside metro Atlanta (the server's bounds, lat 33 to 34.6, lng -85 to -83.6) are refused with a message to type a ZIP. Location is never saved.

It talks to the same live server as the web app (`https://atlas-team12.vercel.app`, `POST /api/extract`, `/api/meaning`, `/api/plan` and `/api/results`, each sent with `x-atlas-surface: android`). There is no mock data in the app. The only built-in text is the labeled sample paper, generated byte for byte from `web/src/lib/sample.ts`.

## Build and test

Needs the Android SDK (platform 36, build-tools 36) and JDK 21 (`brew install openjdk@21`). Gradle 8.14 does not run on JDK 25.

```sh
cd mobile/android
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
./gradlew testDebugUnitTest assembleDebug        # unit tests + debug APK
bash scripts/release.sh assembleRelease           # signed release APK (R8 on)
```

`scripts/release.sh` reads the upload keystore password from the macOS Keychain (service `atlas-android-keystore`, account `atlas-release`) and the keystore from `~/.android-keystores/atlas-release.jks`. Neither is in the repo. Without them, `assembleRelease` produces an unsigned APK.

Outputs: `app/build/outputs/apk/debug/app-debug.apk`, `app/build/outputs/apk/release/app-release.apk`.

## Layout

```
app/src/main/java/com/stephensookra/atlas/
  MainActivity.kt, AppModel.kt   App entry, flow state, API calls, saving
  data/                          Kotlin mirrors of web/src/lib/schema.ts, plan.ts, resources.ts; ApiClient; SessionStore; Sample (generated)
  services/                      TextReader (ML Kit OCR), Reminders + receivers, Speaker (TextToSpeech), LocationProvider
  ui/                            Home, Check the text, Your steps, What gets in the way, Your plan, Reminders, About, theme
app/src/test/                    JUnit tests; resources/fixtures/ are real responses captured from the live API (shared with iOS)
scripts/                         gen_sample.py, make_sample_paper.py, release.sh
screenshots/                     Emulator screenshots of the release build against the live API
```

## Scripts

- `python3 scripts/gen_sample.py` regenerates `Sample.kt` from the web sample. `SampleTest` fails if they drift.
- `python3 scripts/make_sample_paper.py` draws the sample paper as a page image (`scripts/out/sample-paper.png`) for testing OCR. Push it to an emulator with `adb push scripts/out/sample-paper.png /sdcard/Pictures/` and pick it with "Choose a photo".

## Privacy

Photos are read on the phone. Only the checked text, the barriers, a ZIP or (if allowed) a one-time location, the language and the optional note are sent to ATLAS. No analytics or tracking code is added by ATLAS. Google's ML Kit libraries send Google anonymous usage and performance metrics about the ML Kit APIs; ML Kit offers no switch to turn that off. Privacy policy: https://atlas-team12.vercel.app/privacy (linked on the first screen and in About).

ATLAS explains your paper. It is not medical advice. Check with your doctor or clinic before changing anything.
