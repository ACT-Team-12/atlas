# ATLAS for Android

The native Android app for ATLAS. It matches the iPhone app (`mobile/ios` on `feat/ios-app`) screen for screen and does the things the web app cannot:

- **Reads the paper on the phone.** "Scan my paper" opens the ML Kit Document Scanner (`play-services-mlkit-document-scanner`, runs on the phone, its models come from Google Play services). Text is read with the bundled ML Kit text recognizer (`com.google.mlkit:text-recognition`, ships inside the app, works offline). If the scanner module is not on the phone, the app asks Play services to fetch it for next time and opens the system photo picker instead. The photo never leaves the phone. The person checks and edits the recognized text, and only that text is sent.
- **Reminders.** "Remind me" on any care step or plan step schedules a local notification with the step title and the line quoted from the paper. It uses an exact alarm when Android allows it, otherwise an alarm that goes off within 10 minutes of the chosen time. Reminders are re-armed after a phone restart or an app update, and each time the app opens (Android drops an app's alarms when it is force-stopped). All reminders are listed with delete.
- **Read aloud** with the phone's text-to-speech voices in the chosen language, one line at a time, with a Stop button. If the phone has no voice for that language, the screen says so.
- **Saved on this phone.** The last care steps and plan are kept as JSON in the app's private files. Backup and device transfer are turned off for app files. "Clear from this phone" removes them and every ATLAS reminder.
- **Call, directions, links.** Call opens the dialer (nothing is dialed for you), Transit directions opens Google Maps in transit mode, program pages open in an in-app browser tab. Call and Open are hidden when the server sends an empty phone or link.
- **Location** (optional, approximate, one time) for nearest clinics. Locations outside metro Atlanta (the server's bounds, lat 33 to 34.6, lng -85 to -83.6) are refused with a message to type a ZIP. Location is never saved.

It talks to the same live server as the web app (`https://atlas-team12.vercel.app`, `POST /api/extract` and `POST /api/plan`). There is no mock data in the app. The only built-in text is the labeled sample paper, generated byte for byte from `web/src/lib/sample.ts`.

## Build and test

Needs the Android SDK (platform 36, build-tools 36) and JDK 21 (`brew install openjdk@21`). Gradle 8.14 does not run on JDK 25.

```sh
cd mobile/android
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
./gradlew testDebugUnitTest assembleDebug        # unit tests + debug APK
bash scripts/release.sh assembleRelease           # signed release APK (R8 on)
```

`scripts/release.sh` reads the upload keystore password from the macOS Keychain (service `atlas-android-keystore`, account `atlas-release`) and the keystore from `~/.android-keystores/atlas-release.jks`. Neither is in the repo. Without them, `assembleRelease` produces an unsigned APK.

Outputs: `app/build/outputs/apk/debug/app-debug.apk`, `app/build/outputs/apk/release/app-release.apk`.

## Layout

```
app/src/main/java/com/stephensookra/atlas/
  MainActivity.kt, AppModel.kt   App entry, flow state, API calls, saving
  data/                          Kotlin mirrors of web/src/lib/schema.ts, plan.ts, resources.ts; ApiClient; SessionStore; Sample (generated)
  services/                      TextReader (ML Kit OCR), Reminders + receivers, Speaker (TextToSpeech), LocationProvider
  ui/                            Home, Check the text, Your steps, What gets in the way, Your plan, Reminders, About, theme
app/src/test/                    JUnit tests; resources/fixtures/ are real responses captured from the live API (shared with iOS)
scripts/                         gen_sample.py, make_sample_paper.py, release.sh
screenshots/                     Emulator screenshots of the release build against the live API
```

## Scripts

- `python3 scripts/gen_sample.py` regenerates `Sample.kt` from the web sample. `SampleTest` fails if they drift.
- `python3 scripts/make_sample_paper.py` draws the sample paper as a page image (`scripts/out/sample-paper.png`) for testing OCR. Push it to an emulator with `adb push scripts/out/sample-paper.png /sdcard/Pictures/` and pick it with "Choose a photo".

## Privacy

Photos are read on the phone. Only the checked text, the barriers, a ZIP or (if allowed) a one-time location, the language and the optional note are sent to ATLAS. No analytics or tracking code is added by ATLAS. Google's ML Kit libraries send Google anonymous usage and performance metrics about the ML Kit APIs; ML Kit offers no switch to turn that off. Privacy policy: https://atlas-team12.vercel.app/privacy (linked on the first screen and in About).

ATLAS explains your paper. It is not medical advice. Check with your doctor or clinic before changing anything.
